# 凭证照片归档系统

一个在局域网内使用的凭证照片归档工具。

电脑导入 Excel 清单后，系统会生成一条独立地址。把地址发给手机或其他电脑，即可按凭证拍照和上传。完成后可导出照片 ZIP 和记录表。

## 主要功能

- 日期、财务组织、凭证号为主要字段，总金额可选。
- 每个拍摄组拥有独立随机地址，各组互相隔离。
- 支持手机拍照、相册批量选择和多次追加。
- 支持大图预览、向左旋转和删除确认。
- 支持状态、年份、关键词筛选和日期正序/倒序。
- 支持导出全部照片 ZIP，并显示后台打包进度。
- 支持导出 Excel 记录表及附件数量。
- 支持“年份 / 月份 / 凭证号”和“日期-凭证号”两种文件夹规则。
- 建组时可选择 24 小时、48 小时或一周有效期。
- 到期后自动删除该组记录、照片和导出文件，释放空间。
- 管理员可调整允许组数、修改有效期或删除分组。

## Windows：双击即可使用

### 第一次使用

1. 安装 [Node.js LTS](https://nodejs.org/)，版本需要 18 或更高。
2. 从 GitHub 下载项目 ZIP，并完整解压到一个固定文件夹。
3. 双击项目里的 `service.cmd`。
4. 输入 `1`，启动服务。

首次启动会自动安装所需依赖，可能需要等待一会儿。以后启动不再重复安装。

启动成功后会显示：

```text
电脑访问：http://localhost:3000
手机访问：http://192.168.x.x:3000
```

电脑打开“电脑访问”地址。手机和电脑连接同一个 Wi-Fi，然后打开“手机访问”地址。

> Windows 首次弹出防火墙提示时，允许 Node.js 访问“专用网络”即可。如果手机打不开，先检查手机和电脑是否在同一个 Wi-Fi，以及电脑是否进入了睡眠。

### 拍完后关闭

1. 确认照片 ZIP 和记录表已经导出。
2. 再次双击 `service.cmd`。
3. 输入 `2`，关闭服务。

只关闭浏览器不会关闭后台服务，需要使用菜单中的“关闭服务”。

### Windows 菜单

```text
1. 启动服务
2. 关闭服务
3. 重启服务
4. 查看状态
0. 退出
```

也可以在命令提示符中执行：

```bat
service.cmd start
service.cmd stop
service.cmd restart
service.cmd status
```

如果启动失败，查看项目目录中的 `service-error.log`。

## macOS / Linux

需要 Node.js 18 或更高版本。

首次使用：

```bash
npm install
chmod +x service.sh
./service.sh
```

输入 `1` 启动。

以后也可以直接执行：

```bash
./service.sh start
./service.sh stop
./service.sh restart
./service.sh status
```

电脑访问 `http://localhost:3000`，手机使用脚本显示的局域网地址。

## 推荐使用流程

1. 启动服务。
2. 电脑打开 `http://localhost:3000`。
3. 下载并填写 Excel 模板。
4. 导入清单并创建拍摄组。
5. 选择文件夹规则和有效期。
6. 保存并分享系统生成的组地址。
7. 使用手机或电脑上传照片。
8. 完成后导出照片 ZIP 和记录表。
9. 关闭服务。

拍摄期间，运行服务的电脑需要保持开机、联网并避免进入睡眠。

## 有效期

普通用户创建组时可选择：

- 24 小时，默认。
- 48 小时。
- 一周。

管理员还可以设置 30 天或长期有效。

有效期结束后，系统会自动永久删除该组的清单、照片、导出包和分享地址。请在倒计时结束前完成导出。

服务关闭期间不会执行清理；如果关闭期间已经过期，会在下次启动时自动删除。

## 管理入口

首页右上角提供“管理入口”：

```text
http://localhost:3000/admin
```

管理员可以查看拍摄组、使用人、照片数量和有效期，也可以调整允许组数、续期或删除分组。

管理员密码保存在：

```text
任务数据/admin.json
```

请勿把管理员密码或 `admin.json` 发给普通使用人。

## 数据位置与备份

全部记录和照片保存在项目目录下的：

```text
任务数据/
```

典型结构：

```text
任务数据/
├── admin.json
├── tasks.json
└── task-任务编号/
    ├── records.json
    ├── exports/
    └── photos/
        └── 2026/
            └── 07/
                └── 记-0001/
                    ├── 照片1.jpg
                    └── 照片2.jpg
```

备份前先关闭服务，然后复制整个 `任务数据` 文件夹。

更新程序时也应先关闭服务并备份 `任务数据`，更新完成后保留原来的 `任务数据` 文件夹。

## 容量和兼容性

- 单张照片最大 20 MB。
- 单次上传总计最大 100 MB。
- ZIP 导出按队列逐个处理，适合普通办公电脑和 N100 等低功耗设备。
- 支持 Windows、Linux 和 macOS。
- 不依赖 Microsoft Office、Python 或操作系统 ZIP 命令。

## 安全说明

本系统按可信局域网环境设计。

- 拥有完整拍摄组地址的人可以访问该组。
- 不要把组地址发给无关人员。
- 不建议直接通过路由器端口转发到互联网。
- 公网部署需要额外配置 HTTPS、身份认证和备份。
